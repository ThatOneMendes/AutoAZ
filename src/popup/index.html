AutoAZ

Extensão que faz a folha AZ automaticamente.

Como usar:

  1. Vá para a aba de atividades
  2. Coloque as matérias e capítulos na caixa de texto
  3. Se você quiser, coloque uma lista de respostas na segunda caixa de texto. O AutoAZ vai usar essas respostas ao invés de responder aleatóriamente.
  4. Aperte o botão "Começar"
  5. Veja o navegador responder tudo sozinho.

Enquanto a extensão está fazendo o seu trabalho o navegador não pode ser usado. Por favor entenda.

Lista de respostas

A lista de respostas é formatada assim: MATÉRIA:CAPÍTULO:RESPOSTAS
Onde cada letra é a resposta de uma questão. A primeira letra é a questão 1. Respostas de questões que não existem serão ignoradas (Letra A para a questão 11 seria ignorada pois a questão 11 não existe, pelo menos nas AZ Checks do 3º ano do ensino médio.)
Caso você coloque uma letra que não existe na questão, o AutoAZ vai responder a questão aleatóriamente.
